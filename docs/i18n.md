# Internationalization (i18n)

Go Fluent Validator supports 11 languages out of the box for error messages.

## Setting Locale

```go
import "github.com/biyonik/go-fluent-validator/i18n"

// Set to Turkish
i18n.SetLocale("tr")

// Set to German
i18n.SetLocale("de")

// Set to English (default)
i18n.SetLocale("en")
```

## Supported Languages

| Code | Language |
|------|----------|
| `en` | English (default) |
| `tr` | Turkish (Türkçe) |
| `de` | German (Deutsch) |
| `fr` | French (Français) |
| `es` | Spanish (Español) |
| `it` | Italian (Italiano) |
| `pt` | Portuguese (Português) |
| `ru` | Russian (Русский) |
| `zh` | Chinese (中文) |
| `ja` | Japanese (日本語) |
| `ar` | Arabic (العربية) |

## Example: Turkish

```go
i18n.SetLocale("tr")

schema := v.Make().Shape(map[string]v.Type{
    "email": v.String().Email().Required().Label("E-posta"),
    "yas":   v.Number().Min(18).Label("Yaş"),
})

result := schema.Validate(map[string]any{
    "email": "invalid-email",
    "yas":   15,
})

if result.HasErrors() {
    fmt.Println(result.Errors())
    // Output:
    // E-posta geçerli bir e-posta adresi olmalıdır
    // Yaş en az 18 olmalıdır
}
```

## Example: German

```go
i18n.SetLocale("de")

schema := v.Make().Shape(map[string]v.Type{
    "email": v.String().Email().Required().Label("E-Mail"),
    "alter": v.Number().Min(18).Label("Alter"),
})

result := schema.Validate(map[string]any{
    "email": "invalid",
    "alter": 15,
})

// Output:
// E-Mail muss eine gültige E-Mail-Adresse sein
// Alter muss mindestens 18 sein
```

## Per-Request Locale

For web applications, you might want different locales per request:

```go
func Handler(w http.ResponseWriter, r *http.Request) {
    // Get locale from header, cookie, or user preference
    locale := r.Header.Get("Accept-Language")
    if locale == "" {
        locale = "en"
    }

    // Set locale for this request
    i18n.SetLocale(locale[:2]) // Take first 2 chars (e.g., "en-US" → "en")

    // Validate
    result := schema.Validate(data)
    // Error messages will be in the requested language
}
```

## Custom Labels

Use `.Label()` to provide translated field names:

```go
// Turkish labels
schema := v.Make().Shape(map[string]v.Type{
    "email":    v.String().Email().Required().Label("E-posta Adresi"),
    "password": v.String().Required().Min(8).Label("Şifre"),
    "age":      v.Number().Min(18).Label("Yaş"),
})
```

## Fallback Behavior

If a translation is missing, the library falls back to English.

## Thread Safety

`SetLocale()` affects global state. For concurrent applications with different locales, consider:

1. Setting locale once at startup
2. Using middleware to set locale per-request
3. Resetting locale after each request
